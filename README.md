# Olist E-Commerce Sales Analysis

An interactive **Power BI dashboard** built using the Brazilian Olist E-Commerce dataset to analyze sales performance and business trends.

## Dashboard Highlights

- Total Revenue & Orders
- Average Order Value (AOV)
- Average Customer Rating
- Year-over-Year Revenue
- On-Time Delivery %
- Monthly Order Trends
- Top 10 Categories by Revenue
- Revenue by Brazilian State
- Order Status Analysis
- Rolling 30-Day Revenue
- Category-wise Monthly Analysis

## Tools Used

- Power BI
- DAX
- Data Modeling
- Data Visualization

## Objective

To transform raw e-commerce data into an interactive dashboard that provides insights into **revenue, orders, categories, geography, customer ratings, and delivery performance**.
